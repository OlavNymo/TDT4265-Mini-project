## Data

The dataset consists of two modalities:

- **LiDAR data**: `/datasets/tdt4265/ad/open/Poles/lidar/`
  - Multiple channels: combined_color, nearir, range, reflec, signal
  - Train/validation/test splits

- **RGB data**: `/datasets/tdt4265/ad/open/Poles/rgb/`
  - RGB images from roadside cameras
  - Train/validation/test splits

Note: The data is stored in a shared location at `/datasets/tdt4265/ad/open/Poles/` and accessed directly from there.
